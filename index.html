04 / ML_INFRASTRUCTURE✦

Batch vs. Real-Time ML Serving

I deployed a house-price regression model on AWS Kubernetes in two modes: batch inference for grouped inputs and a real-time API for individual requests. I tracked model experiments, containerized both serving workloads, and measured API latency to compare serving behavior.

AWS EKSKubernetesDockerFastAPIClearMLLightGBMLatency benchmarking
Project notes

The serving interface exposed single and batch prediction endpoints along with health and model information.

Streaming Credit Card Fraud Detector

On a cloud computing team, I worked on a pipeline designed to score transactions as they arrive. I built the transaction generator and contributed the Kinesis ingestion infrastructure and deployment tooling so teammates could reproduce and extend the ingestion setup.

PythonAWS EC2KinesisCloudFormationAWS CLIInfrastructure as codeStreaming ingestion
Project notes

06 / APPLIED_ML✦

Avocado Sales Region Classification

I trained models to predict the sales region from avocado prices and sales attributes. I compared Random Forest with logistic regression and XGBoost, then evaluated the model across regions to see where it was most and least reliable.

Pythonpandasscikit-learnRandom ForestXGBoostStratified cross-validationMacro F1
Project notes

Random Forest reached 79.1% test accuracy and about 0.79 macro F1.
